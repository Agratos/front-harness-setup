## 시행 4 — `pm-trial4` (방어 능력 실험)

하네스: main `e227339` (**verify → E2E 코드 강제** 반영)

### 왜 반복 대신 실험인가

시행 1에서 이런 일이 있었다.

> `e.currentTarget` 을 setState 업데이터 안에서 읽어 **두 번째 입력에 앱이 통째로 죽는** 버그가
> `typecheck`·`lint`·`check-arch`·**단위테스트 10개**를 전부 통과하고,
> `eval-playwright` 루브릭은 **종합 100 / major 0** 을 줬다(조작을 안 하므로 초기 렌더만 본다).
> 오직 `eval-scenario` 만 잡았다 — 그런데 **그 러너를 호출하는 코드가 어디에도 없었다.**
> md 3곳에 "⛔ 무조건 실행"이라 적혀 있을 뿐이었다.

즉 그 시점의 하네스는 **죽은 앱을 만점으로 병합하는 상태**였다. 이것이 진단 문서 F3·F4의 실측이다.

### 실험

1. `loop.mjs` verify 가 `eval-scenario` 를 직접 실행하도록 코드화 (`e227339`).
2. 새 복사본에 step 01 을 구현하고 **같은 버그를 일부러 심는다**.
3. **사람이 E2E 를 따로 돌리지 않고** `node scripts/loop.mjs` 만 호출한다.
4. 판정 — verify 가 실패하고 `verify` 에 머무르면 성공, `evaluate` 로 전진하면 실패.

### 결과 — ✅ 성공 (하네스가 스스로 막았다)

`node scripts/loop.mjs` 세 번(design → implement → verify) 외에 **아무것도 하지 않았다.**

```
[scenario] [FAIL] crash — 앱 언마운트 감지, 남은 단계 중단: Cannot read properties of null (reading 'value')
[scenario] 결과: FAIL — 시나리오 2개, 실패 단언 1건
[loop] 결정적 페이즈 'verify': done-gate ok / eval-scenario(scen-step-0-r0) exit 1 — 상호작용 단언 실패(기능 결함)
[loop] 'verify' 실패 1/3 — 구현결함 (결정적 게이트는 green — 상호작용(E2E) 단언 실패로 판단) → 같은 페이즈 재시도
phase: verify   failures: verify=1/3   escalations: 0/3
```

수정 5건이 모두 실제로 발화했다:

| 수정 | 증거 |
| --- | --- |
| **F4** verify → E2E 코드 강제 | 사람이 안 불렀는데 `eval-scenario(scen-step-0-r0)` 가 실행됨 |
| **T1-5** pageerror 수집 | 첫 실패 줄에 근본원인 `Cannot read properties of null (reading 'value')` 가 그대로 |
| **T1-6** fail-fast | 크래시 감지 후 남은 단계 중단 → 실패 단언 **6건 → 1건**, `textGone` 거짓 통과 사라짐 |
| **결함 3분류** | 게이트 green + E2E 실패 → **구현결함** 으로 정확히 분류 |
| **실패 라우팅** | `verify` 에 머무름, `failures: verify=1/3` — 전진 차단 + 카운터 동작 |

### 시행 1 ↔ 시행 4 대조 (같은 버그, 다른 하네스)

| | 시행 1 (v2) | 시행 4 (v3 1단계) |
| --- | --- | --- |
| 게이트 4종 | 통과 | 통과 (동일 — 버그는 정적으로 안 보임) |
| 단위테스트 | 10 passed | 10 passed (동일) |
| 루브릭 평가 | **100 / major 0** | (verify 에서 막혀 평가까지 못 감) |
| E2E 실행 주체 | **사람이 수동으로** | **드라이버가 자동으로** |
| 실패 진단 | "Timeout 30000ms" × 6, 원인 불명 → 진단 스크립트 자작 | 첫 줄에 근본원인 명시 |
| 병합 여부 | **머지됨(100점)** | **차단됨** |

**결론**: "죽은 앱이 만점으로 병합되는" 경로가 닫혔다. md 의 ⛔ 지시를 코드 게이트로 옮긴 것이 실제로 작동한다.
